এক ফাংশন env(), আর সিক্রেট কোথাও নেই

base.py-তে একটি পাসওয়ার্ডও লেখা নেই — সব .env থেকে
def env(key, default=None):
    value = os.environ.get(key, default)
    if value is None:
        raise RuntimeError(
            f"Missing required environment variable: {key}. "
            f"Copy .env.example to .env and fill it in.")
    return value

SECRET_KEY = env("SECRET_KEY", DEV_INSECURE_KEY)
DEBUG = env_bool("DEBUG", False)
ALLOWED_HOSTS = env_list("ALLOWED_HOSTS", "127.0.0.1,localhost")
ফাংশনব্যবহার
env()স্ট্রিং; না পেলে স্পষ্ট এরর, নীরব None নয়
env_bool()"1/true/yes/on" → True
env_list()কমা দিয়ে ভাগ করা তালিকা
কেন স্পষ্ট এরর? os.environ.get() চুপচাপ None দিলে অ্যাপ চালু হয়, তারপর অর্ধেক কাজ করে — ভুলটা তখন অনেক দূরে খুঁজতে হয়।
.env.example-এ ৫টি কী — কিন্তু কোডে পড়া হয় ৪টির বেশি: DB_NAME/DB_USER/DB_PASSWORD/DB_HOST/DB_PORT ডকুমেন্টেড নয়। নতুন কেউ সেটআপ করতে গেলে অনুমান করতে হয়।
শিক্ষকের নোট: .env কখনো Git-এ যায় না — .gitignore-এ আছে। আর .env.example যায়, কারণ তাতে কোনো আসল মান নেই। এই দুই ফাইলের পার্থক্যটাই নতুন ডেভেলপারের প্রথম পাঠ।
