SubscriptionGateMiddleware — লিখা বন্ধ, ডেটা অটুট

পড়া কখনো বন্ধ হয় না; মুছে ফেলা কখনোই হয় না
নিয়মবাস্তবে
SAFE_METHODSGET/HEAD/OPTIONS/TRACE কখনো ব্লক হয় না
ALLOW_PREFIXES/accounts/ /renew/ /platform/ /static/ /media/ /admin/ /healthz /workspaces/
ORG_ADMIN/renew/?blocked=1-এ পাঠানো হয়
অন্য সবাইড্যাশবোর্ডে ফেরত + বার্তা: "আপনার কাজ হারায়নি"
প্রথমে ভুল ছিল: মিডলওয়্যার সেশনের workspace দেখত, URL-এর নয়। এক শিক্ষক নিজের ব্যক্তিগত স্পেসে থাকা অবস্থায় মেয়াদোত্তীর্ণ স্কুলে POST করলে গেট পাশ করে যেত। সমাধান: _workspace_in_url() — পথ থেকে slug পড়া। 
if request.method in SAFE_METHODS:
    return self.get_response(request)

workspace = (self._workspace_in_url(request)
             or getattr(request, "workspace", None))
if workspace is None or any(
        path.startswith(p) for p in ALLOW_PREFIXES):
    return self.get_response(request)

if is_writable(workspace):
    return self.get_response(request)
# ... রিনিউ পাতায় পাঠানো
সুপারইউজার ছাড় নেই: প্ল্যাটফর্ম-অ্যাডমিনও যদি ওই স্কুলের অ্যাডমিন হন, তবু লিখতে পারবেন না — কেবল /platform/ খোলা।
শিক্ষকের নোট: এখানে দুটি নীতি একসাথে: (১) বিলিং মানে ডেটা জিম্মি নয়, (২) অনুমতি URL দেখে, সেশন দেখে নয়। দ্বিতীয়টি না থাকলে এক স্কুল অন্য স্কুলের মেয়াদে ব্লক হয়ে যেত।
