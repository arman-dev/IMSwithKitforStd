def _csv_response(filename, header, rows):
    resp = HttpResponse(
        content_type="text/csv; charset=utf-8")
    resp["Content-Disposition"] = (
        f'attachment; filename="{filename}"')
    resp.write("\ufeff")   # BOM: Excel-এ বাংলা ঠিক দেখায়
    writer = csv.writer(resp)
    writer.writerow(header)
    for row in rows:
        writer.writerow(row)
    return resp

শিক্ষকের নোট: এখানে সততার পাঠ: "যা করতে পারে না, তা কোডে লেখা নেই। স্কুলকে CNAME বানাতে হবে — আমাদের কাজ লাইনটা ছাপা, ভান করা নয়।"

৩. Level 1 ভাঙুন (৭ মিনিট)

৪. যাচাই (৫ মিনিট)

আপনার মডেল ফাইল খুলুন — DFD-র প্রতিটি স্টোরের টেবিল আছে? টেবিল আছে কিন্তু স্টোর নেই — কোথায়?

যাচাইয়ের প্রশ্ন: DFD দেখে একজন নতুন ডেভেলপার বলতে পারবে "উপস্থিতির ডেটা কোথা থেকে আসে?" — না পারলে ছবি অসম্পূর্ণ।
শিক্ষকের নোট: চতুর্থ ধাপটাই আসল কাজ — ছাত্ররা দেখবে তাদের কোডে এমন টেবিল আছে যা DFD-তে নেই (বা উল্টো)। সেটাই পরের ক্লাসের (ERD) সূচনা।
