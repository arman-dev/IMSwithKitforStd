স্কুলের রঙ ঢোকে একটি ভেরিয়েবল দিয়ে

base.html-এ ৯ লাইন — আর ৭৫টি পর্দার রঙ বদলে যায়
<style>
  :root {
    --ims-indigo: {{ brand.color|default:"#4f46e5" }};
    --ims-brand:  {{ brand.color|default:"#4f46e5" }};
  }
  .btn-ims, .ims-nav.is-active,
  .ims-auth__submit { background: var(--ims-brand); }
  .ims-sidebar { background: linear-gradient(180deg,
      color-mix(in srgb, var(--ims-brand) 22%, #0b1220), #0b1220); }
  a { color: var(--ims-brand); }
</style>
কৌশলকেন
CSS ভেরিয়েবল ইনজেক্ট৭৫ টেমপ্লেটে একটি রঙের নাম লিখতে হয় না
color-mix()স্কুলের রঙ যাই হোক, sidebar-এর গাঢ় সংস্করণ নিজে বানায়
default:"#4f46e5"রঙ না দেওয়া স্কুলও ভাঙে না
শুধু ভরাট রঙ, লেখার রঙ নয়লেখার রঙ বদলালে কনট্রাস্ট ভাঙতে পারত
সীমা: স্কুল যদি খুব হালকা রঙ দেয় (যেমন #fde047), সাদা লেখা পড়া যায় না — কনট্রাস্ট যাচাই করা হয় না, কেবল ফরম্যাট যাচাই হয়।
একই পদ্ধতি, দুই স্তর: পণ্যের নামও একইভাবে আসে (product.name সেটিংস থেকে), তাই "IMS" শব্দটি কোথাও হার্ডকোড নয় — একবার PRODUCT_NAME বদলালে পুরো অ্যাপ বদলায়।
শিক্ষকের নোট: জিজ্ঞেস করুন: "স্কুলকে পুরো রঙ-তালিকা দেওয়া যায় না কেন?" উত্তর: ১২টি রঙের সমন্বয় ঠিক রাখা অসম্ভব; একটি রঙ দিয়ে বাকিটা নিজে বানানোই নিরাপদ।
