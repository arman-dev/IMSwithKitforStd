শর্তসাপেক্ষ unique — "একটাই active", ডেটাবেজেই আটকানো

৮টি UniqueConstraint(condition=…); পাইথন নয়, ডেটাবেজ সত্য বলে
class AcademicTerm(TimeStamped):
    is_active = models.BooleanField(default=False)

    class Meta:
        constraints = [
            models.UniqueConstraint(
                fields=["workspace"],
                condition=Q(is_active=True),
                name="uniq_active_term_per_workspace",
            )
        ]
অর্থ: যেসব সারিতে is_active=True, তাদের মধ্যে workspace অনন্য। বাকি সারি যত খুশি।
