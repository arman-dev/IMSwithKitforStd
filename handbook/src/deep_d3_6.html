scoping.py — এক জায়গায় "কে কী দেখবে"

তালিকা-কোয়েরি আর বস্তু-যাচাই একই ফাংশন ডাকে, তাই কখনো মতভেদ হয় না
def visible_students(user, workspace, membership=None):
    qs = StudentProfile.objects.filter(workspace=workspace)
    if membership is None:
        return qs.none()

    if role == ORG_ADMIN:
        return qs                       # পুরো স্কুল

    if role in (COORDINATOR, TEACHER):
        return qs.filter(
            enrollments__is_active=True,
            enrollments__class_group__in=
                visible_classes(user, workspace)).distinct()

    if role == STUDENT:
        return qs.filter(pk=student.pk)  # কেবল নিজের

    return qs.none()
ফাংশনকী ফেরত দেয়
visible_classesভূমিকা অনুযায়ী ক্লাসের queryset
visible_studentsওই ক্লাসগুলোর সক্রিয় ছাত্র
visible_examsছাত্রের জন্য কেবল is_published + নিজের নম্বর
visible_homeworkছাত্রের জন্য কেবল প্রকাশিত
teacher_can_access_class()একই ফাংশনের .filter(pk=…).exists()
কারণ: তালিকা ও বস্তু যাচাই আলাদা লজিক হলে একদিন একটি পথ খোলা থেকে যায় — তালিকায় দেখা যায় না, কিন্তু URL জানলে ঢোকা যায়।
শিক্ষকের নোট: এই ফাইলটিই ডেকের হৃদয়। প্রশ্ন করুন: "নতুন ভূমিকা যোগ করলে কত জায়গায় বদলাতে হবে?" উত্তর: এক জায়গায় — scoping.py. এটাই ভূমিকা-বাগ একবার ঠিক করার নকশা।
