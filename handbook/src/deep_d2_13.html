    if membership:
        return membership

আসল বাগ: প্রথমে রেজলভিং ছিল "lazy"। কিন্তু lazy_obj is None সবসময় False — তাই workspace-হীন ইউজার None-চেক পাশ করে ভেতরে ঢুকে যেত।
সমাধান: রিকোয়েস্টের শুরুতে সরাসরি রেজলভ (eager) — প্রতি রিকোয়েস্টে একটি ছোট indexed কোয়েরি।
শিক্ষকের নোট: এই বাগটি শিক্ষার্থীদের সবচেয়ে বেশি কাজে লাগবে — "lazy মানে ফ্রি নয়"। lazy অবজেক্টে is None কাজ করে না; শুধু if obj ডাকলে সত্য-মিথ্যা বোঝা যায়। এটাই ছিল আসল ফাঁদ।
