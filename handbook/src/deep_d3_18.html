২৩ ধরনের কাজ লিপিবদ্ধ — আর একটি নীরব ফাঁদ

audit.log() কখনো রিকোয়েস্ট ভাঙে না — কিন্তু তাই কিছু চুপচাপ হারায়ও যায়
def log(request, action, obj=None, ...):
    try:
        return AuditLog.objects.create(
            workspace=..., actor=request.user,
            action=action, before=..., after=...,
            ip_address=request.META["REMOTE_ADDR"])
    except Exception:      # noqa: BLE001
        return None        # অডিট কখনো ভাঙবে না
দাম: লগ লেখা ব্যর্থ হলে কেউ জানে না — ডেটাবেজ ভরে গেলে, বা কলাম লম্বা হলে, ইতিহাস নীরবে ফাঁকা থেকে যায়।
